# GTLang 性能 / Performance

> [English](en/PERFORMANCE.md)

> 双后端：LLVM（编译）+ Cranelift（JIT）｜ 优化级别 -O0..3

---

## 1. 编译流水线优化

| 优化 | 位置 | 说明 |
|---|---|---|
| 常量折叠 | opt::inline_and_fold | 编译期计算常量表达式 |
| 常量传播 | opt | 已知常量替换 |
| 函数内联 | opt | 小函数就地展开 |
| 死代码消除 | opt | 不可达/未用移除 |
| 范围分析 | range | 省略已知范围下标的冗余边界检查 |
| 冗余 load/store 消除 | codegen | SSA 值缓存（var_cache/perm_cache） |
| 整数溢出检查消除 | range | 已知安全时省略 |

---

## 2. 运行时性能特征

| 操作 | 复杂度 | 说明 |
|---|---|---|
| 数组下标 | O(1) | 栈分配，边界检查 |
| 列表 push/pop | 均摊 O(1) | 增长数组（容量翻倍） |
| 集合 insert/has | 均摊 O(1) | 开放寻址哈希表（容量 2 的幂） |
| 映射 get/insert | 均摊 O(1) | 开放寻址哈希表（Fibonacci hashing） |
| 字符串拼接 | O(n) | StringBuilder（rt_sb_*） |
| 字符串查找 | O(n*m) | — |
| 通道 send/recv | O(1) | 无界队列 + 互斥锁 |
| `go` 任务派发 | ~µs | AOT/JIT 均用固定 worker 线程池（非每任务起线程） |

## 3. 双后端对比

| 维度 | LLVM（--c） | Cranelift（--run） |
|---|---|---|
| 编译速度 | 慢（clang） | 快（内存 JIT） |
| 运行速度 | 快（优化充分） | 中（基线） |
| 产物 | 独立 exe | 无（内存） |
| 适用 | 发布 | 开发/脚本 |

## 4. 内存管理

| 对象 | 分配 | 回收 |
|---|---|---|
| 结构体 | 栈 | 作用域退出 |
| 定长数组 | 栈 | 作用域退出 |
| 元组 | 堆块 | 进程退出（RC 基础已就绪） |
| 列表/集合/映射 | 堆 | 进程退出（RC 基础已就绪） |
| 枚举/Result/Option | 堆块 | 进程退出（RC 基础已就绪） |
| 字符串 | 堆/静态池 | 进程退出 |
| 闭包 | 堆块 | 进程退出 |

**注**：RC 基础（gt_rc_inc/dec）已实现，插桩待续；当前长运行程序可能内存增长。

## 5. 与 Python 性能对比（理论）

| 维度 | GTLang | Python |
|---|---|---|
| 类型 | 静态 | 动态 |
| 执行 | 编译为机器码 | 字节码解释 |
| 循环 | 原生机器码 | 解释器开销 |
| 函数调用 | 直接调用 | 动态查找 |
| 整型 | i64 装箱 | 任意精度对象 |
| 数组 | 原生/紧凑 | list 指针数组 |
| 预期 | **10-100×** Python（数值密集） | 基准 |

**注**：未做正式基准；GTLang 无 GIL、静态类型、LLVM 优化，数值/循环密集场景预期显著快于 CPython。

## 6. 运行基准

    gtc --run bench/xxx.gt        # JIT
    gtc bench/xxx.gt -o x.exe -O2 # 编译（-O2）
    gtc bench/xxx.gt -o x.exe -O3 # 编译（-O3）

`bench/` 下有基准程序（见 `doc/bench.md`）。
