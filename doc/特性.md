# GTLang 特性清单 / Feature Reference

> 完整、可检索的特性索引。用法细节见 [LANGUAGE.md](LANGUAGE.md)，标准库见 [STDLIB.md](STDLIB.md)。

## 1. 语言定位

- **AOT 编译**（LLVM 后端，`gtc --c file.gt`），无解释器/JIT。
- **零 `.lib` 分发**：标准库以共享 DLL（`res/lib/*.dll`）提供，运行时按需 `LoadLibrary` 加载。
- **语法接近 Rust/Go**，但类型系统更轻（`int` 裸 i64，`decimal` 高精度）。
- **Unicode 标识符**（含中文）：`计数器 := 0`、`fn 加法(...)`。

## 2. 类型系统

| 类型 | 说明 |
|---|---|
| `int` | 裸 i64（**溢出回绕**，C 语义）；字面量/算术/打印直出 |
| `f64` | 双精度浮点 |
| `bool` | true/false |
| `str` | UTF-8 字节串（`len` 为**字节数**，字符数用 `utf8_len`） |
| `list[T]` | 动态数组（引用，堆） |
| `map[K,V]` | 哈希表（MurmurHash3 + 开放寻址，装载因子 0.7） |
| `set[T]` | 哈希集合（`insert`/`has`/`len`） |
| `[T; N]` | 定长数组（栈分配） |
| `(T1, T2)` | 元组（堆块，`t.0` 访问） |
| `enum` | 代数数据类型（`E::V(payload)`） |
| `struct` | 结构体（可泛型 `struct Box[T]`） |
| `dyn Trait` | 动态分发（vtable） |
| `Option[T]` / `Result[T,E]` | 可选/结果 |
| `decimal` | 高精度十进制（`decimal("1.5")`） |

## 3. 声明

```gt
x := 2              // 推导，可变
let mut y = 3       // 推导，可变
let n: int = 4      // 显式类型
const C = 10        // 常量（编译期传播）
let (a, b) = (1, 2) // 元组解构
```

**变量遮蔽**：`if`/`for`/`while` 块**引入新作用域**（可 shadow 外层）；**裸 `{}` 块不隔离**（解构依赖）。

## 4. 控制流

```gt
if c { } else if d { } else { }
while c { }
do { } while c
for i in 0..10 { }
for x in list { }
for ... { } else { }        // 未 break 时执行 else
loop 3 { }                  // 计数循环
loop { if c { break } }     // 无限循环
outer: for i in 0..3 { break outer }   // 标签
match x { 1 => {...} 2 | 3 => {...} n if n > 5 => {...} _ => {...} }
match x { 1..4 => {...} }
```

`break`/`continue`、标签 `break`。

## 5. 函数与闭包

```gt
fn add(a: int, b: int) -> int { a + b }
fn id[T](x: T) -> T { x }                     // 泛型
fn maxx[T](a: T, b: T) -> T where T: Ord { }  // where 约束
f := |x| x * 2                                // 闭包
n := 10; g := |x| x + n                       // 捕获
```

- **函数作一等值**（存变量/传参/返回/放容器/if 分支）。
- **高阶函数**：参数类型**省略**（推断为闭包），**不能写 `f: |T| -> T`**（限制）。
- 无捕获闭包 = 普通函数（提升为 `__closure_N`）。

## 6. 结构体 / 枚举 / trait

```gt
struct P { x: int, y: int }
struct Box[T] { v: T }
impl P { fn dbl(self) -> int { self.x * 2 } }
trait Shape { fn area(self) -> f64 }
impl Shape for P { fn area(self) -> f64 { ... } }
enum E { A(int) B }
@derive(Eq, Clone, Debug, Display, Default)
struct Q { x: int }
dyn Shape(sq)                    // 动态分发
```

## 7. 并发

```gt
go worker(args)                  // 新线程（真线程池）
ch := chan()                     // 无界通道
chan_send(ch, v); v := chan_recv(ch)
chan_send_batch(ch, list); chan_recv_batch(ch, n)
```

- **M:N 协程**（GTO，`gto.dll`）：真线程池 + Vyukov 无锁队列 + 条件变量超时。
- 锁：`mutex`/`rwlock`/`sem`/`barrier`/`cond`/`atomic`/`once`/`sleep`。

## 8. C 互操作

```gt
C {                                        // 内联 C（自动桥接头）
    static long long triple(long long x) { return x * 3; }
    static long long call_gt(long long x) { return gt_add1(x) * 10; }  // 调 GTLang
}
extern "C" { fn strlen(s: str) -> int }    // 调 C 标准库
fn gt_add1(x: int) -> int { x + 1 }
```

## 9. 错误处理

```gt
fn f() -> Result[int, str] { Ok(1) }
x := f()?                                  // ? 传播
try { throw "e" } expt e { } fily { }      // try/catch/finally
assert(cond)
```

## 10. 模块

```gt
import math                                // 标准库（DLL）
import "m.gt"                              // 用户模块
import a.b.c                               // a/b/c.gt
```

## 11. 优化等级

| 等级 | AST pass | clang |
|---|---|---|
| `-O0` | 无 | -O0 |
| `-O1` | 折叠/传播 | -O1 |
| `-O2`（默认） | +if 剪枝/删无用变量/CSE | -O2 |
| `-O3` | +内联/LICM | -O3 |
| `-O4` | +多轮激进 | -O3 + `-march=native` |

**优化不改变语义**（`-O0` 与 `-O4` 输出一致，已测试）。

## 12. 构建/工具

- `gtc --c file.gt -o out.exe -O4` — 编译为 exe
- `gtc --check file.gt` — 仅前端/类型检查
- `gtc --emit-llvm file.gt` — 输出 .ll
- `gtc --emit-optimized-gt file.gt` — 输出优化后 .gt（可再编译）
- `gtc --native` — 对任意 -O 等级开 `-march=native`
- `--no-gc`、`--no-overflow-check`、`--verbose`、`--json`（lint 输出）

## 13. 已知限制

| 限制 | 说明 |
|---|---|
| `len(str)` 字节数 | 字符数用 `utf8_len` |
| 高阶函数无闭包类型 | 参数省略类型 |
| `json_dumps` 仅转义 | 无对象序列化 |
| `while` 无 `else` | 仅 `for ... else` |
| 泛型结构体字面量不写 `[T]` | `Box { v: 42 }` |
| `set` 用 `insert` | 非 `push`；`has(s, v)` 查存在 |
| `startswith`/`endswith` | 非 `starts_with`/`ends_with`（`import string`） |
| `strip(s, chars)` 需 2 参 | 去两端空白传 `""`（`import string`） |
| `find(s, sub)` 返回下标 | 未找到返回 -1（`import string`） |
| 元组解构仅 `let (a,b)` | 不支持 `a,b := (..)` |
| listcomp 不支持范围 | `[x for x in list]`，非 `0..5` |
| 元组不能作 match 模式 | `match t { (1,2) => ... }` 不支持（明确拒绝） |
| `format(tmpl, args)` 的 args 用 **`\n` 分隔** | 非 list；如 `format("{} + {}", "2\n3")`（`import string`） |
| `loop` 只接受计数 `loop N` | 无无限 `loop { }`（用 `while true`） |
| `match` 不支持绑定 `n @ pat` | 用 `n if n in range` 或嵌套 |
| 无 `or` 运算符 | `Option` 解包用 `match` |
| 无 `chan_close` | 通道不支持关闭（用哨兵值/退出标志） |
| `select` 无（无多路复用） | 用多 goroutine + 通道 |
| `impl[T]` 泛型 impl 不支持 | 泛型方法需其他方式 |
| 裸 `{}` 块不隔离 | 解构依赖 |
| `serve_fn` 已移除 | 随解释器移除 |
| `defer` 函数级、编译期登记 | 循环内只登记 1 次（非 Go 运行时累积）；局部变量引用在函数末尾可能失效 |
| `loop_lcg` 的 C 块无法内联 | C 块跨编译单元 + 全局状态（LTO 已尽力） |
| `chan` 双层函数指针转发 | `gto.dll` 运行期加载，架构必需 |
| GC 环回收默认关闭 | `GC_COLLECT_ON=0`，需正确插桩 |
