# Vix Neovim Support

Copy or symlink the contents of this directory into a Neovim runtime path, for example `~/.config/nvim`.

Provided files:

- `ftdetect/vix.lua` detects `*.vix` files as `vix`.
- `syntax/vix.vim` highlights keywords, comments, strings, numbers, types, macros, attributes, and TODO-style comment markers.
- `indent/vix.vim` keeps indentation after pressing Enter inside brace blocks and dedents closing braces/brackets/parentheses.
